# 串口终端模式

点击底部「终端」旁的分屏图标可打开双串口终端。左右两侧分别选串口、设置波特率并连接，点击对应终端即可向该串口输入。右侧使用 8N1 和无流控。退出分屏会断开右侧串口，左侧连接继续运行。

右侧波特率下拉框提供常用速率。需要其他速率时，选择「自定义…」，输入数值并确定，再连接串口。

在底部选择串口和波特率并打开连接，点击设置按钮旁的“终端”即可进入；点击“文本”回到原来的可编辑日志视图。

两个视图共用当前串口连接。切换模式不会关闭串口，也不会清空文本或终端内容。原来的文本接收、Hex 显示、日志保存、图表和发送面板继续使用原有流程；终端直接解析设备返回的原始字节。

终端支持逐键输入、方向键、Tab、退格和 ANSI 控制序列。历史命令和 Tab 补全由设备上的 Shell 或固件提供。

点击任一终端后，按 Ctrl+V 或 Ctrl+Shift+V 向该串口粘贴。选中文本后按 Ctrl+C 或 Ctrl+Shift+C 复制。没有选择文本时，Ctrl+C 发送中断字符到设备。macOS 也支持 Command+C 和 Command+V。

- **本地回显**：默认关闭，由设备回显输入；设备不回显时可打开。设备已经回显时再打开会显示两份输入。
- **回车发送**：默认 CR，可单独选择 LF 或 CRLF。此设置独立于原发送面板的换行符。
- **清空终端**：只重置终端画面和历史缓冲区，保留原文本视图。
- **保存日志**：点击对应终端的按钮，选择位置保存 UTF-8 `.log`。文件名默认带串口号，内容包含该终端的可见文本和仍可向上滚动的历史。

终端模式、回车格式和本地回显设置会自动保存。打开终端后，每个终端保留当前画面和最多 5000 行滚动历史，可在关闭窗口前导出。普通文本视图支持持续捕获到文件。

实现采用 [xterm.js](https://github.com/xtermjs/xterm.js) 与官方 Fit 插件。由于本项目使用 Electron 7，固定使用已在该运行环境中验证的 `xterm@4.19.0` 和 `xterm-addon-fit@0.5.0`，无需升级现有 Electron 或串口模块。

运行 `yarn test:terminal` 可以使用模拟串口检查真实 Electron 窗口中的按键字节、ANSI / UTF-8 显示、模式切换、原有收发行为以及重启后的设置恢复；测试不会打开真实串口。
